Minion V43 安装使用说明
适用系统：Windows 7 SP1 64 位
========================================

一、安装前准备

1. 确认电脑为 Windows 7 SP1 64 位。
2. 准备内网模型接口地址、准确的模型名称，以及 API Key（接口需要时填写）。
3. 电脑需要能够访问该模型服务。安装包不包含大模型权重。
4. 包内已携带 Java、Python 及常用数据分析依赖，无需另装 Java、Python 或 Maven。

二、完整解压

1. 将整个压缩包解压到可读写的目录，例如 D:\Minion-V43。
2. 不要在压缩包中直接运行程序，也不要只复制 minion-0.1.0.jar。
3. 请保留 jdk8、python、prerequisites 等文件夹和启动脚本。

三、安装系统运行库

1. 首次在这台电脑使用时，右键 Install-Prerequisites.cmd，选择“以管理员身份运行”。
2. 按提示安装 Windows 通用运行库和 Visual C++ 运行库；若系统已经安装，可跳过重复安装。
3. 安装器要求重启时，先重启电脑，再进行下一步。
4. 此步骤使用包内离线安装文件，不需要联网下载；不包含 Windows 系统或 SP1 升级包。

四、启动与配置模型

1. 双击 Start-Minion.cmd 启动程序。
2. 打开“设置 → 模型”，添加或编辑需要使用的模型。
3. 按模型服务提供方的参数填写内网接口地址、模型名称、API Key 等信息，并保存。
4. 选择该模型作为新会话默认模型；也可以在会话输入区选择当前会话使用的模型。
5. 新建对话，发送一条简单消息，确认模型能够正常回复。

五、设置工作空间

1. 添加工作空间，选择需要处理文件的项目目录。
2. 建议先准备一个测试目录和测试文件，确认文件读取、数据分析等功能正常后，再处理正式资料。
3. 基础聊天、文件操作、Excel/Word/PPT/PDF 处理及 SQLite 等功能可使用包内环境运行。

六、常见问题

1. 双击后没有窗口：运行 Debug-Minion.cmd，查看控制台中的错误提示。
2. 提示缺少 DLL 或运行库：运行 Install-Prerequisites.cmd，按提示安装并重启。
3. Python 或文档处理报错：运行 Check-Environment.cmd；检查结果保存在 java-check.txt 和 python-check.txt。
4. 模型无法连接或报错：检查内网网络、接口地址、端口、模型名称和 API Key。
5. 程序运行日志位于安装目录下的 .minion\logs\minion.log。

七、可选功能

浏览器操作需要本机兼容的 Chrome；OCR 需要 Tesseract。
网页、EXE、APP 等开发或构建功能可能还需要 Git、Node、PyInstaller、Android SDK 等工具链。
这些可选外部工具、Office/LibreOffice、第三方 MCP 服务和数据库驱动不一定包含在本安装包中，需要按实际功能另行配置。
未配置这些可选工具，不影响基础聊天、文件及常用数据分析功能。

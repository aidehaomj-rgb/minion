Minion custom.4 增量更新
========================

发布日期：2026-08-31
兼容环境：Windows 7、JDK 8、Python 3.7.6/Anaconda3、Qwen3 27B
代码提交：39c6e4e
已合并 GitHub upstream/main：58b7951

本包包含 custom.3 之后至 2026-08-31 的全部本地开发和上游更新。

主要更新：

1. 合并上游工作空间、项目级技能、AskUserQuestion 容错、子 Agent 模型热切换等更新。
2. Anaconda SQLite：Python 子进程自动补齐 Conda 根目录、DLLs、Library\bin、Scripts，诊断改为真正导入 sqlite3。
3. PDF：保留内置 Java PDFBox；附带 Python 3.7.6 可离线安装的 PyPDF2、pdfminer.six 及固定依赖 wheel。
4. 对话滚动：增加“最新对话”按钮，一键回到底部并恢复流式跟随。
5. 上下文：模型调用前主动自动压缩，保留任务状态并显示压缩前后 token，失败时防重复压缩。
6. 运行中引导：执行期间输入补充指令先进入“待引导区”，点击“立即引导”后才注入；新会话可直接输入。
7. 运行提示：“正在加载中/可随时补充信息”移动到输入框左侧，不再遮挡思考和回复。
8. 会话状态点：黄色呼吸表示执行中，绿色常亮表示执行完成未查看，点击查看后消失。

更新安全：

- 更新前校验 SHA-256。
- 自动备份旧 JAR，替换失败自动恢复。
- 可双击 Rollback-Minion.cmd 一键回退。
- 不覆盖 model.json、workspace.json、config.properties、mcp.json、session、skills、知识库、Python 或 JDK。

Python PDF 模块：

- Agent 的普通 PDF 文本解析不依赖 Python，更新 JAR 后即可使用。
- Python 数据分析代码若需要 PyPDF2/pdfminer，请运行“安装Python-PDF模块.cmd”，路径可作为第一个参数传入。

验证：JDK 8 完整测试 798 项通过，0 失败；JAR 打包成功。

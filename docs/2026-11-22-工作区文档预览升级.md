# 工作区文档预览升级

日期：2026-11-22

## 目标

把成果工作区从“单页图片/纯文字预览”升级为统一的离线分页阅读体系，覆盖 PDF、PPT/PPTX、DOCX 原版视图、XLSX 多 Sheet 和图片缩放，并保持 Java 8、Win7 SP1 x64、内网和无新增重型依赖。

## 架构

### 统一 PDF 页面后端

新增 `PagedPdfPreview`：

- 使用现有 PDFBox 2.0.30 打开 PDF。
- 只按需渲染当前页，前端预取相邻页。
- 页图 LRU 最多 6 页，缓存像素总量上限 24MP，单页渲染边长上限 2400。
- 提供整页文本和全文提取，供文本模式与查找使用。
- 关闭时释放页缓存并关闭 `PDDocument`。

### JavaFX 分页阅读器

新增 `PagedSlideViewer`：

- 上一页、下一页、输入页码跳转。
- 左侧缩略图条按需异步加载。
- 单页大图与连续滚动 ListView 两种模式。
- 适应宽度、50%-200% 缩放、Ctrl+滚轮缩放。
- 左右方向键、PageUp/PageDown 翻页。
- 所有 PDF 渲染在独立单线程执行器执行，不阻塞 FX 线程。

### Office 转 PDF 统一管线

新增 `OfficePreviewConverter`，转换优先级：

1. Microsoft PowerPoint/Word/Excel COM
2. WPS COM
3. LibreOffice headless

转换结果缓存到 `%TEMP%/minion-office-preview`，缓存键包含源文件路径、大小、mtime 和类型，7 天自动清理。所有子进程有 45 秒超时和进程树清理。
设置页“文档/OCR”中的 LibreOffice 路径会直接参与探测，也支持手动浏览选择 `soffice.exe`。

### 各格式行为

- PDF：直接进入统一分页阅读器；文本模式首次切换时后台提取全文。
- PPTX：
  - 有 Office/WPS/LibreOffice 时转 PDF，完整显示全部页。
  - 转换失败时使用 `PptxCardViewer` 16:9 卡片，展示每页标题、要点和内嵌图片。
  - “大纲”模式使用原有 OOXML 文字提取。
- DOCX：保留默认快速文本；后台检测 Office/WPS/LibreOffice，可用时提供“原版”分页按钮。
- XLSX：纯 Java 安全解析 OOXML，多 Sheet 页签、200 行 × 30 列上限、复制 CSV；不引入 POI。
- 旧 `.doc/.ppt/.xls`：优先转换 PDF；无转换器时给出明确提示。
- 图片：上限提升到 10 MiB；后台按视口安全下采样，提供适应窗口、100%、缩放和拖拽平移。

### 总览封面

`ArtifactThumbnailService` 为 PDF/PPTX 异步生成首页封面：

- PDF 直接渲染第一页。
- PPTX 优先转换 PDF 后渲染第一页。
- 无外部转换器时使用第一页内嵌图片。
- 封面缓存到 `%TEMP%/minion-preview-covers`，不阻塞成果总览。

## 安全边界

- 不执行 Office 宏、域、外部关系和嵌入对象。
- PPTX 卡片与 XLSX 解析仍走现有 ZIP/XML 安全边界和大小上限。
- HTML 继续禁用脚本、外链资源、表单与弹窗。
- 所有 Office 转换进程有超时和强杀，不在 FX 线程等待。
- 分页渲染和转换均使用有界队列，慢请求可被后续请求替换。

## 验证

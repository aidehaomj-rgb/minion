# 单次流式重复恢复（未发布）

## 改动

OpenAI兼容流式接口收到连续6段高度相似的工具执行承诺（至少5段相似，段长至少20字符）时结束当前响应，结束原因记为`repetition_guard`。检测分别作用于正文与思考，跨SSE分片也可识别；无换行文本按最多160字符分段。短计划、普通报告、代码块、表格和引用不是检测目标。

提前截停仅取消当前HTTP请求，不取消共享客户端的其他请求。出现工具参数增量时关闭该响应的检测，防止截断/重跑有效工具；同一帧先处理工具存在通知。收到的文本仍显示于会话事件中，但循环响应不写入模型历史，不作为任务进度或完成证据。没有收到服务端usage时用估算值并标记estimated。

主Agent和子Agent下一次请求使用V27工具动作恢复协议（关闭思考、支持时tool_choice=required，能力不支持时原有回退）；每轮总恢复预算3次，仍循环则明确暂停、未完成。权限与确认不变，用户主动停止不自动恢复。不修改8192默认输出上限、上下文容量或压缩阈值。

## 边界

检测是针对截图中工具承诺重复的保守启发式规则，不是所有语义循环检测。SFM Agent网关远程负责工具执行，当前不对其传输提前截停；不能承诺模型总能在恢复后输出真实动作。既有历史中的重复段本次不自动删改。未在用户内网实测，本次不打包。

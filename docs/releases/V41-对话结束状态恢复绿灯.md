# V41：对话结束状态恢复绿灯

## 改动

- 运行中的会话继续显示黄色呼吸灯。
- 一轮对话结束后，无论内部任务状态是“已完成”还是“已暂停/等待继续”，左侧会话列表和顶部页签都统一显示绿色未查看提示。
- 内部完成、暂停、等待用户和断点信息仍分别保留，不改变任务续接与完成核验逻辑。

## 原因

V38 起为暂停状态增加了橙灯，但用户容易把它理解为执行异常，也与旧版“对话结束即绿灯”的视觉习惯不一致。V41 只恢复显示颜色，不掩盖或改写内部任务状态。

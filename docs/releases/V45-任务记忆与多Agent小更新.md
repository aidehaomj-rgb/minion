**路径限制：任何一级目录名不要以`!`结尾。** Java8会把路径中的`!/`误判为JAR资源分隔符，导致默认配置等资源无法读取。上次打包正是因此在极端目录测试失败，而非缺少配置文件。普通中文/空格、`&`以及目录内部非末尾`!`已用实际补丁JAR核验；建议使用普通中文/空格目录。原生JNA加载修复不能被说成所有Java8资源路径都无条件支持。

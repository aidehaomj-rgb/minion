# Minion V34 累计更新

本包是完整 JAR 替换更新，包含 V33 的全部功能，以及此后对长上下文结束核验、顶部会话状态灯的修复。无需先安装 V33。

## 修复内容

- 修正 Windows 7 上 `certutil` 将 SHA-256 按字节加空格输出时，安装脚本误报“Package SHA-256 check failed”的问题。仍会严格校验更新包和复制后的 JAR，不跳过校验。
- 结束核验返回损坏的结构化结果时，有限次恢复执行；对长会话中“只规划、不调用工具”的空转整理旧历史。不能据此虚报任务完成，核验仍须有真实证据。
- 顶部页签与左侧会话栏统一显示：运行中黄灯、完成未查看绿灯、查看后隐藏。

## 安装

1. 将 ZIP **完整解压到普通文件夹**，不要直接在压缩软件中运行脚本。
2. 可先在命令提示符执行 `Update-Minion-V34.cmd /verify`，只检查包的 SHA-256，不修改已安装文件。
3. 双击 `Update-Minion-V34.cmd`，按提示输入安装目录（其中须有 `minion-0.1.0.jar`）并确认。脚本会备份旧 JAR，再替换；出现 `V34 update completed successfully` 才算成功。
4. 项目、聊天记录、模型配置、知识库和技能目录不由此包删除。备份留在安装目录的 `backup` 文件夹。

若仍出现 SHA-256 错误，请不要手工跳过校验；记录安装器显示的 Expected/Actual 值，并重新完整解压或重新下载 ZIP。此包在本机构建、哈希和 ZIP 内容已核对；实际内网 Windows 7 安装仍需现场验证。

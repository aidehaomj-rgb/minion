# 任务完成时间（V29）

主任务最终完成标记通过已有完成校验、本轮成功且未中断后，程序从本机时钟生成“完成时间：yyyy-MM-dd HH:mm:ss（北京时间）”。阶段回复、普通问答、子任务返回、完成声明被阻塞、中断或失败不添加。时间不是模型生成。

时间加入最终回复保存内容并在界面显示；完成标记在历史中仍保持末尾，reasoning_content及工具消息配对不变。重新打开历史、导出和任务报告沿用已保存的完成时间，不会改成查看时的时间。

JDK8编译及完成状态、主循环、工作流、会话控制和动作恢复相关测试通过，失败/错误为0。新增测试验证固定时钟的北京时间格式、界面和历史一致、完成标记保持末尾、被阻塞及普通回答不显示完成时间。

已纳入V29更新包，现有V28压缩包不含此项及完成断点刷新修复。未修改用户内网安装。

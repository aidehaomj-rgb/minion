## 范围及本地适配

- Write/Edit：进程内路径锁，编辑读取/检查点/写入全周期串行化，同目录唯一临时文件替换，保留原编码和本地追加模式。确认流程在加锁之前。Windows路径锁忽略大小写；临时文件写失败不直接覆盖原文件。仅保护Minion文件工具，外部Bash/其他进程并发修改不受路径锁保护。
- Read full：普通单行2000字符、单次30000字符；显式full=true放宽至约100000字符，预留尾提示空间。极端超长单行提示转Bash处理，不返回offset自指循环。主/子Agent显式Read full保留工具返回完整内容，其他工具继续本地落盘预览，不取消上下文节省策略。
- 数据库：被截断表格另存未截断版本，20000字符以上大字段另存未转义原文；读取CLOB内容，返回导出路径。
- 子Agent：使用已有唯一任务ID隔离思考/正文/工具/提示/结束事件，主/子独立流缓冲；完成和失败都回收子任务显示缓冲。旧无身份的历史事件保持兼容，不猜测来源。新事件没有改动模型Message协议和任务恢复记录。

# V29：完成收尾与完成时间

适用于已安装 V27 或 V28 的 Windows 7 离线版，累计包含 V28 的循环保护、默认模型、历史分页和上游选择性迁移。保留本地压缩策略及既有功能。

## 新增修复

- 最终文件合法更新后，可实际复核并通过 AgentControl refresh_checkpoint 刷新已登记文件哈希；status 显示实时差异，查询本身不刷新断点。
- 修复“完成声明→查询状态→完成声明”反复续跑。控制面恢复本轮最多12次，完成声明被阻塞时最多3次恢复，不再因工具查询清零；状态满足时正常结束，持续冲突则明确暂停，不伪报完成。
- 缺失文件、未完成待办、未核对子 Agent 和权限保护保留；不会仅凭完成标记自动认定文件正确。
- 主任务通过完成校验后，程序自动附上“完成时间：yyyy-MM-dd HH:mm:ss（北京时间）”。时间取本机时钟，历史、导出及报告保留。阶段回复、失败、中断或被阻塞的完成声明不添加。

## 安装

1. 先退出 Minion，完整解压本包。
2. 双击 Update-Minion-V29.cmd，选择原安装目录（其中应有 minion-0.1.0.jar）。
3. 输入 Y，看到 completed successfully 后用原来的启动方式打开。

只更新 JAR 内应用类和主题，不覆盖模型设置、压缩阈值、知识库、项目与会话记录。旧 JAR 独立备份到安装目录 backup 下的 pre-v29 文件，失败时脚本尝试恢复；回退时先退出 Minion，把该备份复制为安装目录 minion-0.1.0.jar。

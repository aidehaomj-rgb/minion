# V28：V27 之后的合并更新

适用已安装 V27 的 Minion Windows 7 离线版。保留此前开发的功能，不整仓库合并上游。

## 本次新增与修复

- 流式重复保护：针对反复承诺调用工具却没有动作的输出，提前结束当前响应，进入有限次数的动作恢复；恢复仍失败时明确暂停，不无限循环。只取消当前请求，不影响其他会话。
- 设置→模型增加“新会话默认模型”下拉框。只改变新建会话；旧会话继续保留自己的模型，输入框模型选择仍只影响当前会话。
- 修复执行中加载历史出现空白；每页增加到 150 条可见内容，历史子任务长输出默认折叠，浏览历史不被后台新消息覆盖。
- 选择性迁移上游并发写入保护：Write/Edit 使用进程内路径锁与临时文件替换，保留本地追加、检查点及权限确认。
- 主/子 Agent 思考、正文、工具与结束事件按任务 ID 隔离，分别管理流缓冲，避免串台。
- Read 支持显式 full=true，单次上限约 10 万字符；数据库大字段和被截断表格另存完整版本。普通工具仍使用上下文节省策略。

## 保持不变与边界

不替换本地自动压缩阈值、模型上下文配置、任务恢复、共享知识库、会话存储和权限规则。没有引入上游固定 65% 压缩策略，也没有修改默认 8192 输出上限。

循环检测是保守规则，不能保证模型总能恢复真实动作。路径锁只保护本进程的 Minion 文件工具，外部 Bash 或其他程序写文件不受保护。用户内网真实服务尚需安装后验证。

## 安装

1. 完整解压更新包，不要只复制单个 cmd 文件；先退出 Minion。
2. 双击 Update-Minion-V28.cmd，输入原安装目录，例如 D:\ai_agent\minion\minion-win7-offline-0.1.0。
3. 选择 Y，看到 completed successfully 后用原启动方式打开。

更新只替换主程序 JAR 内的应用类和主题，不覆盖 model.json、config.properties、项目、知识库和会话数据。更新前的 JAR 会独立备份到安装目录 backup 下，名称含 pre-v28；失败时脚本尝试恢复该备份。需回退时先关闭 Minion，将该备份复制为安装目录 minion-0.1.0.jar。

## 验证

JDK8 编译及全套回归共 1263 项：1260 项通过，3 项跳过，失败/错误均为 0。JavaFX 验证覆盖历史分页、默认模型、主/两个子任务交错输出、思考折叠和显示缓冲回收。打包阶段另外验证 V27 基础 JAR 应用更新后的类/资源一致性及入口完整性。

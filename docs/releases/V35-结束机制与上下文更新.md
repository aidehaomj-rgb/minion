# Minion V35 累计更新（2026-10-18）

本包是完整 JAR 替换更新，包含 V34 及之后的本地改动，不需要逐版安装。项目、会话、模型配置、知识库与技能目录不在安装脚本的删除或替换范围内。

## 本次修复

- 结束核验区分“模型结束一次回复”与“当前任务真正交付”。候选回复仍有明确可执行步骤、又没有请求用户资料或授权时，不因核验器返回 `waiting_user` / `unknown` 就直接停下；继续执行仍受无进展预算约束，避免无限循环。
- 已返回失败的工具步骤不再全局阻断其他已授权工作或后来已核验的交付；同一可能已产生副作用的操作仍禁止盲目重试。执行结果不可读取时仍暂停并要求核对。
- 用户登记的验收规则暂时无法核验时，进入结束核验而非直接结束本轮；最终交付仍需满足验收证据。
- 长回复和大量工具收据使用有界首尾预览交给结束核验器，完整内容摘要仍参与版本校验；不再仅因结束核验输入超过 48K 字符而直接暂停。
- `qwen3.8-flash` 不再误套旧千问 3.8 非 Flash 模型的 60K 安全窗口。使用 1M 窗口须在该模型设置中填写 `1000000`；若会话单独指定过 60K 安全窗口，将其改为“自动”。服务端实际容量以部署为准。

## 安装

1. 将 ZIP **完整解压**到普通文件夹，退出 Minion；不要直接在压缩软件中运行脚本。
2. 可先运行 `Update-Minion-V35.cmd /verify`，只校验包，不修改安装目录。
3. 运行 `Update-Minion-V35.cmd`，输入含有 `minion-0.1.0.jar` 的安装目录，确认后安装。出现 `V35 update completed successfully` 才表示完成。
4. 脚本会在安装目录的 `backup` 下保留旧 JAR，并对源包与复制后的 JAR 验证 SHA-256。若校验失败，不要跳过；请重新下载并完整解压。

内网 Windows 7 的实际安装和具体模型行为仍需现场验证。修复目标是避免可继续工作的任务被误判为必须等待用户，不意味着网络失败、明确中断、权限不足或执行结果不可读取时会无限重试。

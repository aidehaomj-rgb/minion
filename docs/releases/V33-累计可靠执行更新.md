# Minion V33 累计更新

本包是完整 JAR 替换更新，包含 V32 的数据分析、材料与读图改进，以及本轮的待引导队列编辑、可靠执行工作台、程序验收、步骤核对、检查点恢复、只读本地计划任务和人工复核记录。无需先安装未发布的 V32 包。

## 安装

1. 把 ZIP **完整解压**，不要直接在压缩包里运行脚本。
2. 双击 `Update-Minion-V33.cmd`，按提示确认 Minion 安装目录（目录内必须有 `minion-0.1.0.jar`）。
3. 脚本核对新 JAR 的 SHA-256，停止正在运行的 Minion，把旧 JAR 备份到安装目录下 `backup`，替换后再次核对哈希。
4. 看到 `V33 update completed successfully` 后，正常启动 Minion；打开任务面板，检查“可靠执行工作台”和待执行队列的“编辑所选”。

原项目、会话、模型配置、知识库路径和技能目录不由此包删除。若更新失败，脚本尝试自动恢复旧 JAR；备份文件会保留。请勿在应用运行时手工覆盖 JAR。

本轮本地 Java 8 回归：1337 项，0 失败、0 错误、0 跳过；JavaFX 工作台构建/切页测试通过。尚未在用户内网模型和实际 Windows 7 电脑上安装验证。严格本地兼容模式不是 OS 沙箱；详细边界见 `可靠执行与待引导编辑-开发说明.md`。

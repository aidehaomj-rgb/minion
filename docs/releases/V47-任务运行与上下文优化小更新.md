1. 退出所有 Minion 窗口，建议备份原安装目录。
2. 完整解压 ZIP，不要在压缩包内运行。
3. 双击 `Update-Minion-V47-Small.cmd`，输入原安装目录（包含 `minion-0.1.0.jar`）。
4. 确认识别的基线，按 Y；看到 `V47 update completed successfully.` 后从原安装目录正常启动。

# 可靠执行与待引导编辑（开发说明）

本轮在 V32 代码上继续开发；**尚未制作更新包、推送仓库或部署到内网电脑**。

## 已接入

- 运行中待引导可从输入区编辑，任务面板可选择具体队列项编辑。队列项有稳定 ID 和修订号，旧会话自动迁移；编辑只改文字，保留图片/附件，已消费或被并发修改的条目拒绝覆盖。
- 可靠执行工作台（任务面板第六页）可登记当前任务的程序化验收规则、启用严格本地兼容模式、检查不确定步骤、预览检查点差异并经人工确认恢复。
- 工具动作记录在项目的 `.minion/reliability/<会话ID>/steps`，记录参数/结果哈希而不是原文；写动作在异常后标为结果不确定，同样动作需要人工核对才可重试。
- 可选隔离子 Agent 输出和人工审阅合并；合并检查源/目标版本，冲突拒绝覆盖。Git 代码项目有显式授权的可选 worktree 操作。
- 模型自检只在点击后发送合成文字/工具/图片请求；样本评测须人工确认匿名数据。结果绑定模型配置指纹，不能由短探测证明服务端最大上下文。
- 应用内 timer/目录文件触发任务默认关闭，启用后无历史补跑、不与本会话其他任务重叠。自动轮次限于所选只读工具；写文件、Shell、Python、子 Agent 需要手动发起。通知目前只在 Minion 应用内显示。
- 本任务执行统计记录程序验收、子任务复核、重复工具参数、不确定步骤、运行耗时与会话级 Token；人工业务复核可记录预期、漏处理、重复、错误数量及说明，**不会凭模型回复计算真实准确率**。

## 使用边界

严格本地兼容模式会拒绝任意 Shell/Python，但它**不是操作系统沙箱**。当前 Windows 7 本地进程没有经验证的文件/网络隔离后端；不要把它等同 Codex 的沙箱。关闭严格模式后，任意代码工具的副作用也不能靠检查点完整恢复。

程序验收只验证配置的文件/表格/计数等事实，不证明业务判断正确；表格差异目前以文件版本与文本预览为主，二进制工作簿没有逐单元格语义差异。模型能力自检、匿名评测和本地计划任务均未在用户内网接口上实际运行。

保留 V32 原有模型、上下文压缩和共享知识库设置。本轮未改变真实内网模型容量或自动压缩阈值。

# V30：统一结束门禁更新

适用于已安装V27、V28或V29的Windows 7离线版，累计包含V29及此前改动。本包不回退此前功能，不覆盖模型、压缩阈值、知识库、项目和历史配置。

## 本次修复

- 一次模型响应结束不直接视为任务完成。主/子Agent拟结束时，独立只读检查当前目标、最新补充、实际工具证据、待办、子任务和登记文件；关键词、回复字数和完成标记不再具有完成放行权。
- 确认完成才结束；还有可执行工作就有界续接。需要用户资料/授权或无法确认时，明确显示原因并保留断点和后续队列，不假称完成、不自动发送后续任务。
- 新补充、任务或证据版本变化使旧审批作废；主/子目标和审批分别隔离，子任务返回后仍须主Agent核对。普通解释回答不强制升级成工具/文件操作。
- 状态查询、失败工具和相同结果不重置无进展预算，防止收尾反复循环。文件核验不占用任务台账锁，不额外读取越界路径。
- 保留完成时间、断点刷新、流式重复保护、默认模型、历史分页、共享知识库、选择性上游迁移和现有压缩设置。

## 安装

1. 先保存当前任务并退出Minion，完整解压更新包。
2. 双击 `Update-Minion-V30.cmd`，选择原安装目录（里面应有 `minion-0.1.0.jar`）。
3. 输入Y，看到 `completed successfully` 后按原方式启动。

不要把更新包当作独立程序启动。脚本只替换JAR内部应用类和主题，先校验补丁SHA256，原JAR独立备份到安装目录 `backup` 下的 `minion-0.1.0.jar.pre-v30-*.bak`。失败时尝试恢复备份；手动回退时先退出Minion，把本次备份复制为安装目录的 `minion-0.1.0.jar`。

## 成本与边界

准备结束时通常多一次短模型请求，使用当前会话模型，不调用外部服务。每个审核请求30秒超时、最多1024输出token；只有结构校验失败最多再请求一次。网络失败/有效unknown不反复重试。审核请求超时不会取消其他执行请求。

审核仍由模型完成，不能保证业务判断永不出错。输入或证据不足时可能明确暂停，需要补验；新成功工具事实仅用于进展计数，不自动证明业务正确。失败子Agent不能直接标为完成，仍需重试或向用户说明。

`sfm-agent`远程执行接口暂不支持此隔离审核，会明确返回unknown，不向远程执行会话注入审核指令；本次重点适配DeepSeek/Qwen等OpenAI兼容聊天接口。不改变上下文窗口、自动压缩阈值和单次执行输出上限。

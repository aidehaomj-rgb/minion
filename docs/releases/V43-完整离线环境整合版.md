# V43：完整离线环境整合版（2026-11-03）

## 基线

- 功能代码：当前本地 V42，包含长会话按需加载、150K 默认压缩、任务续接/记忆等此前功能。
- 运行环境：用户提供的 `E:\software\Minion-Win7-x64-offline.zip`（2026-09-28 R2）。
- 完整包自带 Zulu Java 8u222 FX x64、CPython 3.7.9 x64、原锁定的 40 个 Python 包、Win7 UCRT 和 VC++ 离线安装器。

## 合并修复

保留 R2 的 JNA 5.13.0 Windows 进程句柄解析，通过 taskkill 清理子进程树；去掉不存在的 `ProcessImpl.getProcessId` 反射。无 Git Bash 时不再等待不存在的 PID 探针。Unix 负进程组编号显式使用 `--`。截图工具先判定路径，再取得浏览器实例。

新增“关于”页版本标记 V43，移除作者联系信息；第三方许可证保留。启动脚本保留包内 JVM、Python、`--relaunched` 与软件渲染，正常启动不做全量自检。

## 打包与隐私

只从 R2 提取运行环境和离线系统依赖，不打包旧程序、旧源码或旧测试结果。应用换成当前完整 fat JAR，并附当前 `src`/`docs` 源码快照。构建目录、Git 历史、模型密钥、工作区、聊天记录、记忆和浏览器登录资料不从开发机复制。

提供手动旧配置迁移脚本：只向新目录复制指定用户文件，不替换 JAR/运行环境、不修改旧目录；遇到目标同名配置就停止。项目文件和项目内知识库保留在原路径。跨电脑迁移时原密钥库可能需要重新录入。

## 范围

不需要逐个安装 V38～V42 小包。离线运行本地基本功能不需另装 Java/Python/Maven；真实模型需配置内网接口。Chrome、OCR、Git/Node、PyInstaller、Android SDK、Office/LibreOffice、ODBC 驱动等外部可选工具并非都已内置，不冒充完成外部环境安装。

检查使用包内实际 Windows Java/Python，而不是换用宿主 Python；测试记录随包保存。Win7 SP1 实机、GUI 绘制、系统补丁安装与真实模型/数据库/浏览器连接仍需目标机验收。

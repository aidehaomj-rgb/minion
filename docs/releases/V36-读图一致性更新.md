# Minion V36 读图一致性更新

这是完整累计更新包，不要求安装过 V35，也兼容之前使用 V35 小更新包后的 JAR。安装只替换 `minion-0.1.0.jar`，不清理项目、会话、模型设置或知识库路径。

## 本次改动

- 对话框附件与本地图片路径统一采用同一套图像校验和编码。PNG/JPEG 在 5 MB 以内优先传原图，避免无谓缩小导致铭牌文字丢失。
- 大尺寸图片在总览之外附加带位置标签的局部切片；可用 `Read` 或 `ViewImage` 的裁剪和旋转参数进一步查看微小文字。
- 若所选模型服务不支持图像输入，明确报错，不再悄悄丢弃图片后仅凭文字继续回答。
- 累计包含此前版本的结束机制、上下文、历史及界面等修复。

## 安装

1. 退出 Minion；把整个 ZIP 解压到普通文件夹，不要直接在压缩软件内运行。
2. 先运行 `Update-Minion-V36.cmd /verify` 检查压缩包 SHA-256（可选）。
3. 运行 `Update-Minion-V36.cmd`，输入包含 `minion-0.1.0.jar` 的安装目录，确认更新。
4. 安装脚本先备份原 JAR 至安装目录的 `backup`，再替换程序文件。若检测到已有 `.jar.new` 暂存文件则拒绝覆盖。

图像识别仍取决于内网模型接口是否支持视觉、服务端图像限制和原图清晰度；本更新不保证每张照片的品牌型号都能被正确识别。

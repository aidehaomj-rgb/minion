# 跨项目共享 Markdown 知识库

用户要求所有项目直接读取同一份 Markdown 知识，不再逐项目同步。具体目录由 Minion 在用户指示下连接，代码中不固定路径。

## 设计

- 全局配置 `knowledge.shared.dir` 默认为空，可在基础设置中浏览或修改，也可由 `Knowledge.connect(path)` 在用户确认后设置；`disconnect` 取消连接。每次查询读取当前配置，已有会话也能生效。
- `Knowledge.search/list` 汇总项目自身 `.minion/knowledge` 与共享目录（含子目录）的 `.md` 文件。共享命中使用 `shared/相对路径` 标识；`read` 支持该标识。
- 共享库只读：`add/import/sync/delete` 保持原有项目级语义，不对外部目录做修改；解析共享路径时校验目录边界及实际路径，拒绝遍历和越界符号链接。
- 共享目录不可用时项目知识库仍可用，查询输出明确提示；不会创建外部目录。
- 检索仍是现有关键词/中文二元组算法，不引入向量服务或同步副本。

## 验证

- 两个项目读取同一共享 Markdown，修改文件后第二次查询可见更新。
- `read` 能读取共享子目录条目；`delete` 不能删除共享条目。
- 目录缺失时不自动创建并给出提示。

# 新会话引导入口设计

## 问题

InputView 在会话间复用。旧会话运行过程中已输入但尚未发送的内容，会在创建新会话后继续留在输入框，造成内容串入。空白新会话也没有明确的开始入口。

## 方案

- 首次启动无会话、以及切换到尚无消息的新会话时，输入框进入引导锁定状态。
- 切换到新会话必须清空旧会话未发送的文本、附件块和补全弹层。
- 操作行显示“开始引导”按钮；点击后只解锁输入框并提示用户描述目标，不自动填充或发送任何提示词。
- 已有消息的历史会话直接恢复普通输入，不显示引导按钮；同一会话的运行状态回调不会重复锁定。
- 引导锁定期间上传和发送不可用，避免键盘或附件绕过入口。

## 验收

- 运行中的会话留有草稿时创建新会话，新会话输入框为空。
- 空白新会话不能直接输入，点击“开始引导”后才可输入。
- 点击引导不会产生用户消息或模型请求。
- 切回已有会话不要求再次点击引导。

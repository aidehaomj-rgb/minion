# 批次 G：浏览器与成果验证

## 边界与设计（2026-11-05）

用户已授权八批并行，本批只改 browser 包、AcceptanceRules、新建验证器及对应测试。不改 BrowserPlugin、SessionManager、BuildTool、AgentLoop、TaskState、TaskWorkflow、总计划或 README；不运行共享 target 的 Maven，不提交、不打包。

- G01：语义探针检查唯一匹配、可见、禁用、遮挡、页面标识及 DOM 版本；iframe 必须显式 CSS 选择，跨域不可读时明确失败，不回退主页面。等待反复重新定位，只有观察可重试，点击/提交不自动重放。
- G02：会话级人工接管阻止 BrowserEval/导航及语义写动作；恢复必须持有接管令牌、人工确认及登录后可见锚点。写动作执行前设置 uncertain 闩锁；回执缺失/传输中断必须核对或人工恢复，不因超时再提交。该内存状态不是重启持久化，主流程必须保留 uncertain 记录。
- G03：下载完成同时需要 CDP completed、受控目录真实文件、非临时文件、稳定尺寸/mtime 及 SHA-256；仅文件存在不通过。分页保存页标识/内容哈希/唯一键/重复与覆盖范围，下一页以数据变化判定，重复页不计新页；无总量/页码断言时不称完整覆盖。上传区分选择文件与服务端回执。
- G04：新 ArtifactVerification 工具通过真实 HTTP GET 验证状态/内容哈希，默认只允许 loopback、禁止重定向；可注入显式内网 URI 策略。可选连接既有浏览器做页面可见断言及本次导航后的 console/失败请求证据；不启动任意进程、不自动公网调用、不把服务进程或文件存在算成功。
- 部分 G05/G06：沿用现有表格规则，增加精确十进制汇总；PNG/SVG 尺寸及 SVG 字体清单可确定性检查，字体实装/排版溢出标 unknown；EXE/APP 只做目标平台/架构头部检查，永不宣称已运行。公式重算、实际 Office 打开、全排版/字体/溢出、Win7/跨平台运行仍未实现。

## 权限与接线

新工具不自行放宽路径/只读策略。文件检查仅工作区及构造注入的授权谓词；默认不额外授权技能目录。HTTP 是受限 GET，不是通用浏览器沙箱；浏览器加载页面会运行页面脚本，webpage 动作不得加入只读白名单。浏览器插件启用 gate 必须保持。注册/schema/测试结果和限制将在本文末追加。

## 验证方式

使用已有 JUnit4/MockWebServer，本地 HTTP/WebSocket 协议模拟与确定性文件测试；独立 target/g-verification-* 下 javac/JUnit，无新增依赖、无外网。协议模拟不等于真实 Chrome/Win7/内网登录实测。最终由主流程统一 Maven 定向及全量回归。

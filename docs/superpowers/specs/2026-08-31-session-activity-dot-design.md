# 会话运行与完成状态点设计

## 状态

- `RUNNING`：黄色小圆点并保留呼吸动画。
- `COMPLETED_UNREAD`：任务结束但用户尚未点击查看，绿色常亮。
- `NONE`：空闲且已查看，不显示圆点。

## 转换

开始运行时清除旧完成标记并进入 RUNNING；运行结束（含正常结束、错误收口或中断收口）进入 COMPLETED_UNREAD；用户从左侧列表或页签激活会话时清除完成标记。状态仅属于本次程序运行的界面提醒，不写入会话文件，重启后不把历史会话误报成新完成。

## 展示

左侧会话列表使用完整三态。页签继续展示运行状态，但也复用统一状态点组件。列表在运行状态变化和激活时刷新，保证颜色立即更新。

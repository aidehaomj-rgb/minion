# 运行中待引导区设计

## 正确语义

引导不是新会话输入门禁。新会话和空白首页始终可以直接输入并发送。引导用于任务执行期间：用户输入补充指令并按发送键后，先暂存到“待引导区”，此时不进入事件流、不写上下文、不通知模型；只有点击“立即引导”才注入当前运行对话。

## 交互

- 运行中有输入：发送按钮显示“加入待引导区”的含义。
- 暂存后：输入框上方显示 `待引导：<摘要>`、`立即引导`、`取消`。
- 再次输入并发送：追加到同一待引导内容，不提前发送。
- 点击立即引导：若任务仍运行，调用现有 `sendSupplement` 在下一个安全检查点注入；若任务恰好已经结束，则作为该会话的新用户消息发送，避免内容丢失。
- 切换会话：清理当前 UI 待引导草稿，防止跨会话误发。
- AskUserQuestion 回答模式保持原有直接回答语义，不经过待引导区。

## 验收

- 新会话可直接输入。
- 执行中第一次发送不出现在聊天记录。
- 点击立即引导后才出现“运行中补充”并进入模型。
- 可以取消待引导内容；任务先结束也能安全发送。

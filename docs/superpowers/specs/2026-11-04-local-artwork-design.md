# 本地高质量绘图（开发）

用户确认：内网只有 DeepSeek V4 Pro/Flash 与 Qwen3.8 Flash，没有独立生图服务，先增强本地绘图。

## 范围

- 新增内置 Artwork 工具，使用 Java 8 自带 Java2D / ImageIO，无 Python、新浏览器、新库、GPU、外网或额外模型要求。
- 可编辑 JSON 场景渲染为 PNG + SVG + 布局报告；默认 2 倍像素，抗锯齿、中文字体回退、自动换行、渐变、圆角、图层、箭头和本地图片组合。保留源稿，迭代修改源稿，默认输出新版本而非覆盖旧图。
- 提供封面、流程、数据概览三类起点，不把模板当最终设计或虚构统计事实。数据图表继续使用 Python/Matplotlib，视觉排版使用 Artwork 或现有 HTML/SVG 工具链。
- 明确文字溢出/画布越界/缺字警告；机械检查不等于视觉审美验收。实际支持看图的当前模型才调用 ViewImage 检查，不自动切换主/子 Agent 模型，不把图像发给纯文本部署造成 400。
- 不声称聊天模型本身拥有扩散生图/写实照片创作能力；不实现公网生图接口、不安装扩散模型、不制作更新包。

## 验证

单测覆盖像素尺寸、透明背景、SVG/XML 转义、文本溢出、字体、局部图片合成、路径权限、拒绝覆盖、预算上限、三类模板及工具注册；渲染实际 PNG 进行人工式像素查看。沿用现有原文/压缩与主子模型一致规则。

## 完成与本机结果（2026-11-04）

- 已注册内置 Artwork，加入 visual-design 技能；统计绘图继续使用现有 Matplotlib，并明确中文字体、真实数据、口径、PNG/SVG与脚本保留。
- 主 Agent 记录实际 PNG 文件证据；只读子 Agent 仅允许查询/inspect，隔离输出子 Agent 的模板/成图仍限制到指定目录。固定格式工具可用于兼容模式，不新增任意代码执行入口。
- 成图不会自动进入模型图像上下文；模拟纯文本 DeepSeek V4 Pro 的完整工具执行/结束流程通过，避免因为不支持视觉导致 400。用户问模型能否生图不被误识别为已经授权画图。

# MINION 桌面App入口与任务栏身份

用户要求：Win7内网继续使用现有Java8/Python环境，具有真正应用入口与桌面快捷方式，可由用户固定任务栏；图标先提供候选，由用户选择。

## 当前检查结果

现有offline-package/启动Minion.cmd实际启动jdk8/bin/javaw.exe，尚不是独立Minion.exe入口。不能只把BAT改名或修改快捷方式图标就声称任务栏身份已经正确。

本机只有.NET4编译器，没有.NET3.5编译器，不能悄悄引入Win7未必安装的.NET4依赖。因此优先采用轻量Win32原生启动器，复用原有Java8；具体编译工具及Win7最低版本必须验证后才能交付。

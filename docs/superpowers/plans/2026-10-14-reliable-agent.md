# 可靠Agent实施计划

1. 稳定队列ID/版本、CAS编辑/取消、输入区和任务面板编辑UI，旧数据迁移测试。
2. 经用户确认的验收规则及确定性文件/范围报告，接入正常结束门禁，版本变化作废旧核验。
3. 工具前后步骤日志、不确定副作用恢复提示；统一严格兼容权限。
4. 可控资源锁、隔离输出与版本冲突合并、分组检查点差异及恢复预检。
5. 人工模型自检、配置指纹与结果失效、无真实业务资料的合成探测。
6. 默认停用的应用内计划任务/文件触发和本地评测记录管理，去重、权限与重启行为测试。
7. Java8串行编译/回归和真实JavaFX控件验证，记录未验证的内网环境和系统沙箱依赖。

2026-10-15 进度：1-6 已实现为本地应用功能；第 7 项 Java 8 完整回归 1337 项、0 失败/错误/跳过，JavaFX 工作台构建与页面切换验证通过。真实 OS 沙箱与内网模型/业务数据实测不在本地可验证范围。详见 `docs/releases/可靠执行与待引导编辑-开发说明.md`。

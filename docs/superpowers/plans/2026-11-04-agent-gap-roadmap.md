# Minion 能力补齐开发任务计划

基线：V44 已交付能力与当前本地源码。用户目标：长任务可靠执行、只记有用信息、开发与办公成果可验证；兼容内网 Win7 SP1 x64 / Java 8 / Python 3.7.6。本文是开发清单，不表示列出的功能已经完成。

## 固定原则

- 采用增量开发，不推倒重写，不增加 OpenAI 服务依赖或要求外网可用。
- 150000 token 默认压缩触发值保持不变；1M 是配置窗口，不作为必须填满的工作目标。
- 子 Agent 继承主会话模型，不擅自切换。视觉/工具能力以实际接口测试为准，不按名字猜测。
- 原始会话事件不被摘要覆盖；最新用户指令高于旧摘要；任务、项目及个人记忆边界不削弱。
- 不取消必要的超时/防循环约束，不靠无限重试掩盖失败。低风险过程不新增大量确认弹窗。
- 单测、协议模拟、实际模型、Win7 真机是四种不同证据；不能互相冒充。
- 逐批验收。除非用户要求，不制作小更新包，也不覆盖已交付的 V44 ZIP/JAR。

## A：优先修复图片回答（代码和本机验证已完成，尚未打包）

- [x] A01 把回答从字符串扩展为文字＋图片快照，保持旧入口兼容；空文本＋有效图可提交。
- [x] A02 修复输入框 ANSWER 分支；仅接收成功才清空，失败保留文字/图片；不把回答误加入新任务队列。
- [x] A03 接通工具结果后的图片协议消息；同轮多工具必须先配对全部 TOOL，再附图片。
- [x] A04 明确回复对应提问；持久化/压缩投影保留关联，历史回放不重复展示，编号含义不丢。
- [x] A05 覆盖仅图、图文、编号＋图、重复提交、取消、多问共享等待、存取与实际 GUI 路由测试。

涉及：`InputView`、`SessionManager`、`AgentLoop`、`AskUserQuestionTool`、`Message`、`ContextManager`、`SessionController`。

出口：现有文字用例全通过；下一 API 请求含真实 image_url 且配对合法；取消不会清除草稿或误投下一任务。纯文本服务仍可能拒图，需明确提示而不是假称识别成功。

本机证据：Java 8 编译；全量1499项、0失败/0错误、1项OCR缺环境跳过；末尾追加的输入状态切换保护经最终173项定向回归（0失败/错误/跳过）和真实 JavaFX 控件检查通过。JavaFX 检查包含图文、仅图、拒收保留草稿及旧提问结束后不误发新任务。406个应用class最高major=52。日志见 `target/question-image-full-tests-final.log`、`target/question-image-focused-tests.log`、`target/question-image-javafx-qa.log`；机器可读清单见 `target/question-image-validation.json`。真实Win7和内网识图服务仍待试机。B-H的后续集成进度与证据见下方和2026-11-05集成检查点；旧V44包不含本开发版。

## B：任务执行从文本提示升级到明确状态

- [x] B01 新增版本化任务步骤记录：stepId、目标、依赖、范围、状态、证据、验收方式；不依赖会话摘要保存控制状态。
- [x] B02 指令变更记录增加 add/replace/cancel/supersede 语义；保留原文与来源，不只把原目标和后续补充累加。
- [x] B03 用已完成步骤、有效文件变化、成功回执等衡量实际进展；有进展时按预算续接，无进展时换方案或报告具体阻碍。替代单纯固定续接次数，但保留用户可见上限与取消入口。
- [x] B04 区分 completed / waiting_user / retrying / paused_budget / blocked / interrupted；等用户必须有具体问题，不以一句“下一步需要”假完成。
- [x] B05 执行副作用前后记录步骤状态；网络中断、进程重启后先核对 uncertain 回执，不自动再次写数据库、发送、删除或支付等。
- [x] B06 压缩/重启交接只带当前任务未完成步骤及最新修订；旧任务引用不能变成执行目标。

出口回放：运行中改目标、取消部分要求、连续压缩、达到轮数、有/无进展循环、工具部分成功、重启不确定状态。验收要求零旧任务复活、零已确认副作用盲重放；必须保留可解释的停止原因。

## C：代码开发、测试和审查闭环

- [x] C01 项目测试发现：Python 优先项目指定命令/已安装 pytest，或 unittest；找不到测试明确标记 not_configured。compileall 只能叫 syntax_check，不能冒充测试通过；不自动安装依赖。
- [x] C02 Java 优先项目 Maven/Gradle wrapper；npm 读取实际 scripts；缺依赖/离线缓存作为环境阻碍，不显示“构建成功”。保留用户自定义验证命令。
- [x] C03 运行结果分离：退出码、测试数、失败/跳过数、耗时、日志文件、测试范围、代码版本；处理超时、编码、进程树退出和取消。
- [ ] C04 接入里程碑验收：失败后读取对应日志，最小修改，再运行相关测试；修复预算耗尽时暂停但不得标完成。
- [x] C05 增加针对真实 diff 的独立只读审查流程；发现带文件/行号/风险/证据；区分格式检查与语义审查，不要求每次小操作都再问一次模型。
- [x] C06 在完成报告区分功能验证、语法检查、未运行检查；文件版本变化后旧测试结论失效。

出口：有意注入语法正确但断言错误的 Python 项目，必须失败；未配置测试不冒充通过；Java/npm 测试失败可定位并修复；审查不修改工作区。

## D：可控、精准的长期记忆

- [x] D01 记忆增加替代/冲突关系及适用条件；新偏好替代旧偏好，项目决定不自动变全局事实。
- [x] D02 在现有中文字词匹配上增加轻量倒排索引/BM25 与别名归一、时间/任务/路径过滤；支持索引重建和增量更新，不强制新增向量服务。
- [x] D03 来源文件变更将关联决定标为待重核；保留历史版本，不把 changed 事实仍当现行结论。
- [x] D04 检索按任务相关性、核验状态、时效和重复片段控制注入；带原文位置，无命中时不编造记忆。
- [x] D05 查看/修改/删除/关闭自动提取入口统一；全局身份与偏好继续由用户控制，跨项目不读取私人对话。
- [ ] D06 建立同义问法、旧决定被推翻、文件更新、跨项目隔离、20万 token 与连续 compact 评测集。

出口：最新修订优先；旧结论有可追溯的失效依据；所有检索引用可定位原文；无默认跨项目私聊泄漏。向量检索只有经实测证明必要且内网有合适服务时另立任务。

## E：模型与性能

- [x] E01 在显式 ModelProbe 基础上保存按接口/模型/配置指纹绑定的能力档案：工具调用、结构化输出、视觉、usage、流式；unknown 不等同支持。
- [x] E02 探测只由用户触发或明确启用；服务端能力变化后可重测，启动不跑全量探测，不为探测发送真实项目资料。
- [x] E03 分开统计排队、首 token、生成、工具、检索、压缩与结束核验耗时，避免把服务端慢误判成本地故障。
- [x] E04 使用实际 usage 校准估算，按文本/工具/schema/图片分项展示；不因校准覆盖用户设定的 150K 默认压缩目标；真实服务端较小窗口仍须约束并解释原因。
- [x] E05 工具 schema/技能按任务按需加载与缓存；长工具结果落盘、去重、按页取回；测量缓存失效与效果，不盲目裁剪关键证据。
- [x] E06 对格式失败、截断、连接失败使用分类恢复；主/子保持同模型，不能以提速为由偷偷换模型。

出口：冷/热启动无新增逐会话扫描；同任务对照记录 token 与耗时；图片拒绝不造成不明 400 重试风暴；未知能力可解释。

## F：多 Agent 交付闭环

- [x] F01 子任务登记依赖、唯一范围、输出契约；父任务能看到等待/运行/待复核/失败/取消，不只看到一段总结。
- [x] F02 调度按并发限额与服务端负载排队；支持取消传播、超时与有依据的重试；故障任务不得拖死所有任务。
- [x] F03 代码任务按需使用现有 worktree 能力，与子任务/会话生命周期绑定；非 Git/Excel 任务继续使用独立输出目录。
- [x] F04 子结果必须有证据路径与验收报告；主 Agent 核对后才采纳，不将子 Agent 的“已完成”直接视作最终验收。
- [ ] F05 合并前检查基线和冲突，保留用户未提交修改；合并后运行联合测试；有冲突不强行覆盖。
- [ ] F06 回放38个分块、乱序返回、部分失败、重复输出、模型切换限制与取消。

出口：分块覆盖率和重复率可计算；一个范围不被重复提交；失败可定位重做；所有子模型与父一致；合并不丢用户改动。

## G：浏览器与成果验证

- [x] G01 增强元素可见/可交互等待、导航与页面版本识别、frame 定位和过期定位恢复；优先可解释的语义动作，不依赖任意固定 sleep。

- [x] G03 下载记录真实文件、完成状态、大小与校验，上传核对页面回执；分页记录页标识/唯一行/覆盖范围，发现重复和漏页。
- [x] G04 网页启动后实际访问并检查控制台/失败请求及关键交互；不能仅以服务进程存在判成功。
- [ ] G05 Excel 核对行列、主键、汇总、公式及导出可打开性；查询/分析保持来源与 SQL/脚本，不凭模型口述认定数值正确。
- [ ] G06 绘图/文档检查尺寸、字体、溢出和实际渲染；EXE/APP 核对目标平台/架构、构建日志与可执行验证。不能运行的目标清晰标记未验证。

出口：分页/下载有完整性证据；网页有实际操作记录；Excel 有确定性业务校验；“已生成”与“已验证可用”明确分开。没有生图服务时不声称支持照片级模型生图。

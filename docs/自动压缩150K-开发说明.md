# 自动压缩触发点调至 150K（源码开发，未打更新包）

- 默认“稳定工作区”从 120,000 改为 150,000 token。对标称 1M 上下文、使用默认值或完成旧值迁移且无更小安全窗口的 DeepSeek 和 Qwen3.8-Flash，自动压缩触发点为 150,000 token。
- 原 `model.json` 中 DeepSeek / Qwen3.8-Flash 保存为 80,000 或 120,000 的稳定工作区，首次用新版源码启动时迁移为 150,000，并保留 URL、API Key 等其他模型配置。迁移有版本标记；此后用户手动调整不会被反复覆盖。原值为 `0` 的配置不必改写，自动使用新默认值。其他显式自定义值及其他型号保持不变。
- 设置页预览同步显示默认 150K。子 Agent 沿用所选主模型的设置，不另设阈值。
- 150K 是稳定工作区软上限，**不是无条件保证恰好在 150K 压缩**：较小的实际安全窗口、百分比阈值、输出预留，以及服务端超限/空响应后的学习结果仍可能提前触发。`/compact` 手动压缩保持原样。
- 不修改模型标称 1M 窗口、历史原文归档、检索与用户指令优先级。内网网关在 150K 长任务下的耗时和可靠性仍需实测。

验证：上下文、设置预览、模型配置迁移、会话切换和子 Agent 等 5 类共 151 项测试通过。全量测试尝试时，HTTP/MCP 本地回环连接被当前沙箱拒绝（`Permission denied: connect`），相关网络夹具测试未能完成；不是内网模型的实测结果。

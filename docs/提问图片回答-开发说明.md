# 回答模型提问时附图片

## 适用场景

Minion 正在执行任务，通过 AskUserQuestion 向你提问并等待回答。现在可以在同一输入框使用回形针上传图片，或粘贴截图，再按当前配置的发送键/点击发送：

- 文字＋图片，例如“按方案2做，错误见截图”。
- 只发图片，不必为绕过空文本检查额外输入一个字。
- 数字选项＋图片，保留选项的完整含义。
- 沿用每条最多3张、单图5MB等现有附件限制；其他文件沿用已有的本地文本提取通道。

## 行为

- 回答被接收后继续当前任务，不另起任务，也不转到下一任务队列。
- 图片真实像素随下一模型请求发送，工具回执仍保持文字协议，避免破坏 tool_call/tool 配对。
- 每个实际提问有短期 ID，输入框携带它提交。取消、提问变化、重复提交或无效附件时拒收，保留文字和图片供你检查，不静默丢弃。
- 聊天区显示回答文字和图片文件名；历史回放只显示一次。协议承载图片不会伪装成新的用户任务；图片仍保存在会话历史。
- 不增加联网服务，不切换主/子 Agent 的模型。模型接口必须实际支持视觉输入；纯文本服务即使可以接收上传界面，也可能拒绝识图。拒图不等于附件链路成功识别了内容。

# V49：运行内核与验证工作台

日期：2026-11-08。基于本地 V48 及 11 月 7 日选择性合入的三个上游修复继续开发。
本轮不制作更新包、不推送 GitHub、不修改正在运行的安装目录。
继续使用 Java 8 / JavaFX 8，不新增依赖，150000 token 完整压缩目标不变。

## 八个方向的具体交付

| 方向 | 本轮实现 | 边界 |
| --- | --- | --- |
| 统一执行 | 主/子工具通过 ToolInvocationPipeline 和 ToolExecutionGuard 共用归属、取消、实际执行与后置验证规则；TurnSemantics 共用可见输出和瞬时错误判定 | 没有一次性重写两个完整 AgentLoop；业务状态仍由原有任务/作业控制器维护 |
| 压缩并发 | 主压缩绑定 session/task/revision/generation/model/context/history；新输入、切换模型/上下文、取消或历史变化后丢弃过期摘要；子压缩同样核对修订与取消 | 不改变 150K，不把压缩器回复当作用户消息已读，不重放旧任务 |
| 作业恢复 | RuntimeJobs.list/inspect/reconcile，核查既有结果文件、外部实例标识及版本；保留变更前状态和人工复核审计 | UNKNOWN 不冒充 completed；不按 PID 重连，不重新提交 SQL；尚无 MaxCompute 真实服务恢复适配器 |
| 代码理解 | CodeIndex.symbols/references/impact，Java/Python/JS/TS 定义与引用候选、行列/哈希/片段，按需限量扫描，每次读取新版本 | 词法近似，不是 LSP、类型推导或传递调用图；无法证明重构安全 |
| 执行 Hooks | before_tool / after_tool / before_complete / after_compact；默认关闭，人工确认配置 hash 后仅本会话启用 | 命令是用户批准的本地程序，不是 OS 沙箱；只读计划任务和隔离子 Agent 不继承根会话脚本 |
| 多 Agent 复核 | 新增只读复核页，展示 task/revision/attempt、执行根、记录路径、状态和回执；64 子任务/每项最近16回执/128KiB 有界投影 | 展示不等于验收，不刷新旧哈希或释放依赖；原始记录保留 |
| 成果验证 | DOCX 文本/物理表格单元格断言；XLSX 指定 sheet/cell 原始值、公式缓存状态；网页可选 PNG 截图及哈希，接入成果引用卡片 | 不声称 Word 分页、Excel 实际重算或 EXE 已运行；截图不是视觉合格证明 |
| 评测回放 | 离线事件/人工标签比较脚本；真实模型协议探测器默认 dry-run，显式执行才访问指定网关 | fixture/mock 不等于内网实测；缺少标签或 usage 保持 unknown，字符串断言不作为业务评分 |

另增项目记忆管理页与 Memory.explain：查看来源、作用域、验证/失效原因、来源指纹、替代与冲突；编辑降为待核验，旧版本保留审计；删除到回收区。
此页只管理当前项目，不自动读取其他项目的私聊或将其提升为全局记忆。
原有子 Agent 表格改用有界元数据/正文节选，TaskState.render 在已有锁内读取当前条目后才截取，不再为展示12条而先JSON复制全部大结果。完整 childSnapshot API 保持深拷贝语义。

## 使用入口

打开任务面板，可看到新增的 **记忆解释、多Agent只读复核、Hooks** 页。
About 显示 `V49开发版（运行内核与验证工作台）`，仍不显示联系方式。

### 代码索引

```json
{"action":"symbols","path":"src","max_files":"200","max_results":"100"}
{"action":"references","path":"src","symbol":"AgentLoop"}
{"action":"impact","path":"src","symbol":"process_data"}
```

工具名 `CodeIndex`，代码任务自动提供 schema，其他任务可通过 DiscoverTools 按需发现。
检查结果的 `complete / truncated / cancelled / errors`，不能把部分扫描称为完整项目分析。

### Office 校验

工具名 `ArtifactVerification`：

```json
{"action":"docx","path":"报告.docx","officeChecks":[{"expectedText":"结论"},{"table":0,"row":1,"column":0,"expectedText":"已核对"}]}
{"action":"xlsx","path":"结果.xlsx","officeChecks":[{"sheet":"Sheet1","cell":"B2","expectedValue":"100","formulaCache":"not_formula"}]}
```

DOCX 表格索引从零开始，合并单元格不做视觉网格还原。XLSX 比较存储原始值，不自动格式化日期或计算公式。
公式缓存状态 `present_unverified` 只表示有存储缓存；实际重算仍需 Office/WPS/LibreOffice 等可运行环境另行验证。
`webpage` 原有检查参数可增加 `screenshotPath`，须为授权目录下尚不存在的 `.png` 路径，不覆盖旧截图。

### Hooks

项目下 `.minion/hooks.json` 示例（路径须按实际环境修改）：

```json
{"hooks":[
  {"id":"check-output","event":"before_complete","timeoutMs":10000,
   "command":["C:\\Anaconda3\\python.exe","D:\\项目\\check_result.py"]}
]}
```

在 Hooks 页读取完整配置和 SHA-256，查看命令后人工批准。模型没有自授权入口。
配置改变、会话重新载入/重建、工作区根改变后旧批准失效。重启需重新批准。
工具动作可用 `tool` 和 `action` 精确匹配；省略 `tool` 表示通配。事件和匹配不是正则表达式。
命令为 argv 数组，元数据通过 stdin 的 JSON 提供，不把模型参数拼入 shell；大参数仅传路径/动作和原始参数哈希。
输出最多16KiB，超时请求停止进程树；用户停止时取消运行中的 Hook。进程取消仍是尽力而为，不保证已发生的副作用回滚。

前置失败不执行目标工具；后置失败明确保留“工具已经执行”，禁止当成没执行而盲目重放。
结束 Hook 失败最多给模型两次纠偏机会，仍不通过则暂停而非显示完成。
Hook 退出0仅表示指定程序返回成功，**不能替代真实测试、业务验收或原有 StopGate**。
禁用时不读取配置、不哈希、不启动进程，也不增加模型请求。

### 作业核对

```json
{"action":"list"}
{"action":"inspect","jobId":"已登记的作业ID"}
{"action":"reconcile","jobId":"已登记的作业ID","previousSha256":"可选的上次哈希"}
```

工具名 `RuntimeJobs`，只在主 Agent 提供。list 支持 offset/limit（默认20，最多50），按最近登记顺序返回元数据；inspect/reconcile 也只提供审计条数而不把完整历史正文注入模型。完整原始账本不删改。只能核查账本已有 resultPath，不能从参数读取任意路径。
状态查询/哈希核查不计为业务进展，不会用观察时间戳变化购买新的自动续接预算。
保存的外部实例ID仅做账本比对，未联系服务端就明确标记未核验。

## 离线评测

Python 3.7.6 标准库可运行：

```text
python -m unittest discover -s tools/qa -p test_replay_runtime_jobs.py
python -m unittest discover -s tools/qa -p test_probe_model_protocol.py
python tools/qa/replay_runtime_jobs.py --before tools/qa/runtime-replay-fixtures/before.json --after tools/qa/runtime-replay-fixtures/after.json
python tools/qa/probe_model_protocol.py --cases tools/qa/model_protocol_cases.jsonl
```

最后一条默认不联网。真实探测须显式增加 `--execute --endpoint <完整chat/completions地址> --model <实际模型标识> --output <报告路径>`。
密钥仅从 `MODEL_API_KEY` 或 `--api-key-env` 指定的环境变量读取，不写入报告。
该探测是非流式协议测试：首响应时间不是流式首 token 时间，不执行任何模型返回的工具调用。
完整长任务、38分块、200K后修订目标等业务回放，仍使用真实任务记录与人工金标准验证，不能用小型字符串案例替代。

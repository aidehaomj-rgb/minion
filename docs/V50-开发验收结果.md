## 兼容性与交互验证范围

- 中文项目/路径、空项目、暂时离线的项目目录仍显示，不自动删除或创建替代目录。
- 同目录的不同项目不合并；跨项目同标题、同会话 ID 分别显示和打开。
- 浏览、搜索、展开/折叠、切换新旧视图只读元数据；旧 workspace/session/order/events/history 夹具逐字节一致，旧 SessionStore 仍能读取原始要求。
- 点击对话才加载正文；慢加载晚于新选择完成时不抢焦点。程序同步顶部页签不会取消较新的待加载导航。
- 顶部跨项目同 ID 页签不串线，关闭页签不删除会话，可以再次打开。
- 项目内新建使用明确选中的项目及其目录；目录不可用时不偷偷改用别的目录。
- 置顶、重命名、归档、删除仅作用于目标项目的所选会话；另一项目的同 ID 原始快照/事件保持不变。运行中的会话不能归档。
- 新界面保留绿色未查看完成提示，沿用原后台任务运行状态；模拟运行状态不会因普通导航被清除。
- 每项目30条分页与较早对话定位；归档显式可查；180px窄侧栏的工具按钮换行，项目“＋”仍可见。
- 偏好不存在不写文件；损坏/未来版本偏好不覆盖；较早后台保存不能覆盖较新界面选择。

原生验证只在隔离夹具中运行，classpath 为测试辅助类目录和最终 JAR，**不含 target/classes**；没有发送真实模型请求，没有执行真实后台长任务。截图是合成示例，不是用户内网数据。

## 边界

本次不迁移项目/会话存储，只新增独立显示偏好。用户主动打开旧会话或执行元数据操作时，仍按既有恢复、150K兼容及保存逻辑运行；不承诺这些明确写入操作也“零改写”。

未对真实内网电脑、真实 Win7 或真实 DeepSeek/Qwen 服务作本轮端到端认证。Python库、上下文/压缩策略、子Agent模型规则及任务续接策略未因侧栏改造而变更。已有安装数据的保证来自实现约束和代表性旧数据夹具验证，而不是声称直接检查过用户内网硬盘。

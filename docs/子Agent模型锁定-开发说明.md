# 子 Agent 模型锁定（V38 后源码开发）

任务子 Agent 强制使用主会话当前运行模型及其配置快照。`task` 不再提供 `model` 参数；即使旧调用传入，也会拒绝，且不会派发任务。任务面板不再提供子 Agent 模型选择。旧会话保存的子 Agent 默认模型在恢复时清除。

运行中禁止手动切换主会话模型；若模型设置在运行中被修改，主会话客户端和之后启动的任务子 Agent 仍使用原快照，任务结束后再一起刷新。旧子 Agent 记录若标注的模型与当前主模型不同，不允许直接续接旧推理，需核对文件后选择重试。

“旁支提问”是无工具、只回答文本的独立请求，不是任务子 Agent；其模型选择功能暂保留，不改变主任务。

回归验证：8 个测试类共 261 项通过；加固切换模型的并发锁后，重新运行相关 2 类共 81 项通过。此源码改动不包含在已交付的 V38 小更新包中，尚未制作新更新包。

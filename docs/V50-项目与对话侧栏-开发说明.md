# V50 项目与对话侧栏

日期：2026-11-08。本轮只由主 Agent 开发，仅修改 Minion，未修改本机 zcode-server。

## 界面与操作

左侧默认改为一个项目树，而不是把“当前项目的对话”和“全部项目”放成两个独立列表：

```text
项目 / 对话                              ⋯
＋ 新建对话   新建项目   打开项目
搜索项目、路径或对话标题

▾ 项目甲 (12) · 当前                    ＋
    ★ 已置顶的对话
      当前工作对话
▸ 项目乙 (8)                            ＋
▾ 空项目 (0)                            ＋
      暂无对话 · 点击新建
```

- **点项目行**：只展开/折叠，不切换执行目录、不打开历史消息、不停止后台任务。
- **点对话**：打开它所属的项目及对话；后台读入历史，最后一次明确导航优先，迟到的旧加载不能抢回焦点。
- **项目右侧 ＋**：在该项目创建对话。顶部“新建对话”使用当前选中的项目，未选中时使用当前项目。
- **搜索**：匹配项目名称、路径和对话标题；不会对全部历史正文做全量扫描。搜索暂时展开匹配项目，不改变原有折叠偏好。
- **较多对话**：每项目先显示 30 条，再按“显示更多”增加；从已打开页签定位较早的对话时自动扩展该项目的显示范围。
- **对话右键**：打开、置顶/取消置顶、重命名、归档/取消归档、删除确认。运行中的对话不能归档。
- **项目右键**：新建对话、项目设置、复制路径。项目树不提供递归删除整个项目的快捷操作。
- **⋯ 菜单**：显示归档、展开/折叠全部、切回“旧版双列表”。旧版的项目/对话手动排序入口仍保留。
- 绿色未查看完成提示、运行提示及顶部页签继续使用原有规则。

目录暂不可用的旧项目仍然列出，历史会话不会自动清除；在该项目新建对话前会提示核对目录。

## 如何保护已有内网数据

**不是数据库迁移，也不要求重新导入项目。**

1. 仍读取原 `workspace.json` 和 `session/<原项目名称>/`，不更改项目身份、不搬动会话目录。
2. 同目录的两个项目保留为两个项目；不同项目的相同会话 ID、相同标题也分别显示。页签和视图缓存按会话句柄关联，避免只按 ID 串线。
3. 原 `session-order.txt`、置顶/归档字段继续使用。旧事件记录、历史归档不重建、不被树视图摘要覆盖。
4. 展开、搜索、切换新旧显示方式仅访问会话元数据，不调用模型、不执行工具、不保存空占位会话。
5. 新增显示偏好只存放在程序同目录 `sidebar-view.json`，包含视图模式、折叠项目和是否显示归档；损坏/未来版本偏好不覆盖原文件，界面回退为本次窗口可用的默认显示。
6. **用户主动打开旧会话**仍沿用此前的恢复、模型回退、150K 配置兼容逻辑；主动置顶、重命名、归档、删除仍会写入所选会话。这些明确操作不属于“浏览零改写”的承诺。
7. “项目设置”中主动修改项目名称仍沿用旧版目录重命名流程，不是本次新增的自动迁移。原有启动日志和可丢弃的会话索引缓存仍按原逻辑更新。

目前未增加树内跨项目拖拽移动会话，避免未经确认改变工具目录、项目记忆和事件归属。

## 参考与实现边界

- 参考 Codex 类工具的项目分组、逐会话打开方式；官方功能入口：<https://developers.openai.com/codex/app/features/>。
- 本机 zcode-server 的 `packages/ui/src/project-sidebar/` 只读参考：展示投影与执行身份分离、偏好独立保存、异步导航的迟到结果不能覆盖较新选择。
- 没有复制其数据表、引入 Node/Electron 或新增在线依赖。仍是 Java 8 / JavaFX 8，保持 Win7 的现有技术基线。
- 项目树为虚拟化列表，刷新合并；历史加载使用独立、有界的后台导航队列，不与模型旁支问答争用同一队列。
- 本轮没有修改模型上下文策略、150K 压缩阈值、子 Agent 模型继承、任务续接和 Python 数据分析环境。

## 复查入口

- `src/main/java/com/minion/gui/sidebar/ProjectTreeModel.java`：只读项目树投影与分页。

- `ProjectSidebarOperationsTest`：跨项目同 ID 的显式归档/重命名/置顶/删除隔离。
- `tools/qa/VerifyProjectSidebarV50.java`：隔离夹具中的真实 JavaFX 8 主窗口、异步竞争、旧版视图和截图。无真实模型调用。

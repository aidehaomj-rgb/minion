# V54：引导标记、过程回复折叠与拖动排序

- 已发送的引导只在原消息上显示「引导·未读」或「引导·已读」。保留回执的真实送达判定；插入、发送中或未确认不算已读。输入区不再重复显示引导摘要，不再有「查看引导」弹窗；尚未发送的「立即引导」暂存操作仍在。

- 项目树排序使用 JavaFX 的鼠标事件，不依赖 Windows 原生拖放剪贴板格式。原项目、会话和排序存储格式不变。

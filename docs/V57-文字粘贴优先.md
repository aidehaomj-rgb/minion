# V57：文字粘贴优先

原输入框优先取剪贴板里的附件或图片，导致 Excel 等应用同时提供纯文本与位图时，复制的文字可能被识别为图片。

现在统一先取纯文本，有文字就不读取附带的图片或文件格式。短文字替换选区或插入光标处；超过 1000 字符以可查看全文的粘贴块显示，仍在原位置按完整文本发送。只有没有文字时才按原有路径接收文件或纯图片。Ctrl+V、Shift+Insert 和原生编辑器粘贴动作共用一个入口，草稿仍按会话隔离。不更改系统剪贴板、剪贴板持久化或模型图片配置。

参考本机 zcode-server 对剪贴板多种表示的区分方式；未引入新依赖。

Java 8 构建成功，86 项定向测试全部通过；覆盖模拟的文字+图片/文件混合剪贴板、长文本原位发送、粘贴入口一致性、纯图与文件回退和草稿恢复。未在真实内网 Win7 或当地 Office 应用中实机复现；本轮未制作小更新包。

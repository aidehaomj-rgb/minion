# 内网回放验收（待真实环境执行，不是已通过证明）

使用匿名测试项目；不要导出真实密钥、身份信息或业务附件。模型探测只用合成输入且由用户显式发起。真实任务数据需先由你确认脱敏，不能用这里的合成案例冒充业务验收。

## 每次记录

Minion版本、Win7补丁/Java/Python版本、实际接口模型标识、配置窗口/150K触发值、开始与结束时间、任务ID、任务结果/停止原因、模型usage是否估算、检索/压缩耗时。任务评估导出后人工填写expectedItems、omittedItems、duplicateItems、incorrectItems、accepted。没有金标准就保持unknown，不能把工具成功率当业务准确率。

## 固定回放

| ID | 操作 | 必须观察到的结果 |
|---|---|---|
| R01 | Agent提问后仅发截图；再试编号+图片 | 接收后继续同一任务；图片进入当前支持视觉的接口；不另起任务；拒收保留草稿 |
| R02 | 长任务累计超过20万token后，将“修改代码”改为“只分析，不修改” | 最新指令优先，旧修改步骤不执行；来源原文仍能定位 |
| R03 | 在执行中连续/compact至少5次 | 继续当前未完成步骤，不完整重读旧任务，不重放成功写入 |
| R04 | 38个不同文件/行段分块交子Agent，乱序返回、一个故意失败 | 范围不重叠；失败分块可定位；成功汇总不丢块；主Agent复核后才完成 |
| R05 | 切换当前模型后继续任务/重试旧子任务 | 子Agent模型与主会话一致；不混用旧推理字段；运行期间不能偷偷换模型 |
| R06 | 记录“偏好A”，明确改成“偏好B”，新会话用同义问法询问 | B是现行偏好；A可追溯但不作为当前事实；未核验信息不永久注入 |
| R07 | 核验的项目决定引用文件v1，随后外部修改文件为v2 | 旧结论标为待核，不继续以已核验事实注入；其他项目私聊不可检索 |
| R08 | Python中写语法正确但断言错误的测试；随后修复 | 第一次必须失败，不能compileall冒充通过；修复后实际测试通过；源码变更使旧报告失效 |
| R09 | Excel含前导零单号、大整数ID、0.1/0.2金额和重复键 | 全表行数/唯一键/精确汇总有证据；不把抽样当全表；源工作簿样式/公式不误报保留 |
| R10 | 本地测试网页含重复下一页、延迟下载、不可见按钮、iframe | 不重复记页/提交；动作等待可解释；下载实际完成/文件哈希明确；遇登录失效交还人工 |
| R11 | 模拟断流/空正文/坏JSON/工具超时，及写入后进程强制结束 | 分类恢复有界；不凭完成词结束；副作用不明先核对，不自动重发数据库写入/发送/删除 |
| R12 | 生成网页、PNG/SVG、Office及EXE/APP，再刻意破坏一项输出 | 区分已生成、结构通过、视觉已检、已实际运行；不能运行的目标明确未验证 |

## 统计与输出

- 先在任务面板查看当前状态/证据与人工业务复核，再导出任务评估JSON。
- 使用Python3.7运行 `tools/qa/summarize_agent_replays.py <手动选中的报告1.json> <报告2.json> --output <新结果.json>`。
- 汇总仅包含你选择的报告，不遍历其他项目/私聊；已有输出拒绝覆盖。未复核、无金标准、零样本均不制造100%成功率。
- 误报完成率的分母仅是“Agent报告完成且人工已复核”的任务；用户主动取消、等待权限和未复核暂停不能笼统算Agent错误停止。

## 环境边界

当前路径授权/确认/操作日志不是操作系统沙箱；Win7不因此具备现代系统级隔离。实际现代Android/前端/打包工具链是否兼容仍需匹配离线依赖，不能因文件存在就声称安装可用。安装路径含`!`的JNA加载已有延迟兼容修复及本机Java8实际子进程回归，仍需Win7真机核对。全量单测、协议模拟、本机JavaFX、真实内网模型与Win7真机结果分别记录，不互相替代。

## 结构化多Agent补充操作

- R04先给每个分块独立输出路径和stepId，scope用相对路径前缀数组，dependsOn显式数组；并发默认2，可用child_capacity降低。不要多个worker直接写同一个Excel文件的不同“行范围”，应各自产出片段再汇总。
- 记录queued/running/returned_needs_review/reviewed/merged_needs_validation/validated，以及失败/取消/超时。只有父任务返回后实际读取文件的回执ID能用于child_review；不能拿状态查询或子回执代替。
- 代码worktree合并前后各刻意修改一次主文件：合并前必须拒绝覆盖派发基线变化，合并后必须让旧联合验证失效，不可仅刷新状态显示成功。
- 杀进程恢复后，child_status应显示recoveryHold；运行状态不明的项保持interrupted_needs_review。child_resume_queue不能自动重跑未知副作用；重试需核对依据和正确attempt，旧记录保留。
- 父任务等待物理执行时不新增主模型请求；最新要求改变或切换主模型后旧子任务不能继续写入/偷偷沿用旧模型。

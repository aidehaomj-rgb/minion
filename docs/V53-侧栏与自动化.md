# V53：侧栏与自动化

## 侧栏

只读参考本机 zcode-server 的 ProjectSidebarNavigation、ProjectSidebarListHeader、ProjectNodeContent 以及 AutomationsSection。采用“顶部全局入口 → 搜索/视图工具 → 项目树”的层级，在 JavaFX 8 原界面中实现，不引入 Web 运行时或 zcode-server 依赖。

- 顶部为「新建对话」「自动化」，搜索收进放大镜按钮；按 Esc 可关闭搜索。
- 在项目栏的「⋯」中创建或打开项目、切换归档显示、展开/折叠以及恢复旧版双列表。
- 项目行使用文件夹和展开图标；窄侧栏自动隐藏次要计数，保留每项目新建入口。
- 原项目/会话拖动、置顶、最近执行顺序和草稿隔离不变。每个项目初始显示 5 条，「显示更多」每次增加 5 条。

## 自动化

点击左侧「自动化」，在独立窗口中选项目及绑定对话。可以新建、编辑、单独启停或删除规则，并查看触发方式、最近触发时间和执行状态。打开窗口不会启动模型，也不会切换主窗口正在编辑的会话。

1. 选定对话，建议用专用对话隔离定期执行和日常工作。
2. 选择按分钟间隔运行，或监听项目内/已授权目录第一层文件的变动（稳定至少 30 秒）。
3. 写入任务指令、勾选允许的只读工具，保存为停用。
4. 确认后启用。启用时记录所选对话当前模型配置；此后模型配置改变、运行失败或上次执行状态未知，规则会暂停等待处理。

此功能仅在 Minion 打开时调度，不安装系统服务、不补跑关闭期间的任务。暂停只停止以后触发，不强制终止当前执行；自动轮次只使用选定只读工具，不能使用 shell、写入或启动子 Agent。调度器本身在本机运行，实际任务仍调用该会话配置的模型。

仍读取原工作台的本地计划任务记录，未迁移项目或会话。旧 JSON 编辑入口保留；日常建议通过新表单单项管理，避免整表替换。同一物理目录下两个项目出现相同会话 ID 时，拒绝共享规则，改用本项目新建的专用会话即可。

此次只交付本地开发构建，不覆盖原安装、不制作更新 ZIP。真实内网 Win7 与模型实际执行需在部署后验收。
